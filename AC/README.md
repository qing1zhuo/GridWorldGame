# 网格世界 Actor–Critic

本项目在原实验的 5×5 地图、奖励 `boundary=-10 / forbidden=-10 / target=10 / blank=0`、折扣率 `0.9` 下，训练并检验最优策略。打开 `main.ipynb` 后从头运行即可看到配置、训练日志、精确评估与策略图。

## 修改参数

`main.ipynb` 的“参数集中配置”单元格显式列出了 `config()` 的全部构造参数，并提供中文注释：地图与奖励、Actor/Critic 学习率、采样量、熵衰减、梯度裁剪、奖励尺度、学习率衰减、停止条件、值迭代精度、随机种子、设备和 CPU 线程数。同一个单元格还可以设置输出目录、日志开关、模型/图片保存开关、图片显示、平滑窗口、DPI 和打印精度。

修改后从配置单元格向下运行，会从头训练。修改模块源码后请重启内核。更换地图不需要修改原地图坐标断言；当前 notebook 的验收按实际地图计算。输入维度由地图大小派生，动作固定为上、右、下、左、停留，当前独立线性头没有隐藏层参数。

学习率公式为 `initial_lr * max(min_lr_ratio, 1 - update / lr_decay_steps)`；`min_lr_ratio=1` 表示不衰减。`reward_scale=None` 按奖励绝对值自动确定归一化尺度。高级误差容限控制验收严格程度，放宽它们不代表策略实际改善。输出中 `summary.json` 保存有效算法配置，`notebook_settings.json` 保存输出与绘图选项。

## 算法与原实验的差别

- `rollout.py`：25 维 one-hot 状态，取代二维归一化坐标。
- `net.py`：独立的线性 Actor 与 Critic，相当于表格参数化的神经网络，避免共享 MLP 在邻近状态之间产生干扰。没有声称验证原 MLP 架构或对未知状态的泛化。
- `train.py`：每次从全部 23 个非终止状态分别抽样 32 个当前策略动作，总计 736 次环境交互；使用新鲜样本做一次更新后丢弃。可以理解为每步都采用均衡起点的一步 AC，需要能任意设置网格起点的模拟器。它不是单轨迹采样，也不是经验回放。
- `runner.py`：使用一步 TD 优势、独立 Adam 优化器、固定奖励尺度归一化和梯度裁剪。初始熵系数 0.02，在 2000 次更新内降为 0；学习率在前 6000 次更新下降到初始值的 10%。没有把最优动作或最优价值用于训练。
- `env.py`：惩罚格仍可进入，进入时扣分；到达目标即终止，未来价值为 0。reset 均匀抽取非终止格，包括惩罚格。终止后必须 reset。全状态训练不需要等待一个可能永不结束的回合。
- `evaluate.py`：值迭代计算最优基准；线性方程精确计算随机策略和贪心策略价值。动态规划结果只用于评估及早停。

原来的地图、奖励及非终止状态的转移保持不变；终止格作为起点并继续获得奖励的行为已被移除。一次新更新包含 736 个样本，因此不能把更新次数直接与旧实验的环境步数比较。

## “收敛到最优”的验收定义

每 100 次更新检查全部 23 个非终止状态，连续 5 次满足全部条件才停止：

1. 贪心动作属于最优动作集合，允许并列最优；匹配率为 100%。
2. 贪心策略最大价值误差小于 `1e-8`。
3. 随机策略最大价值误差不超过 `0.05`，以原奖励单位计。
4. Critic 与当前随机策略真实价值的最大误差不超过 `0.1`。

这里严格最优的是部署时的贪心策略；有限 logits 的随机策略只达到数值容限，并不声称非最优动作概率严格为零。该验收覆盖固定网格，不能推论任意环境必然收敛。

## 实测结果（2026-09-26，CPU）

五个随机种子均通过连续 5 次验收，贪心策略最大误差均约 `1.78e-15`。

| 种子 | 停止更新数 | 随机策略最大价值差 | Critic 最大误差 |
|---|---:|---:|---:|
| 123456 | 5500 | 0.009852 | 0.039534 |
| 1 | 5300 | 0.012041 | 0.040047 |
| 2 | 5400 | 0.012107 | 0.056506 |
| 3 | 6100 | 0.008605 | 0.026716 |
| 42 | 5300 | 0.010778 | 0.061183 |

默认种子使用 4,048,000 个环境样本。所有非终止起点均匀加权的最优平均折扣回报为 `7.47092652`，贪心策略达到同一数值。详细结果见输出目录中的 `summary.json` 和 `seed_validation/summary.json`。

按图中从 1 开始的行列编号，`(5,3)` 学会向上，`(5,4)` 学会向左，正确利用下方目标。

`(3,2)`、`(4,1)`、`(5,1)` 的最优价值为 0。它们到达目标前必须受到至少一次 -10 惩罚，而目标奖励只有 +10，折扣后不如无限期安全停留；最后两个格之间的安全移动也可以是并列最优。因此不能用“所有起点均到达目标”衡量当前奖励下的最优性。

## 输出与复核

- `model.pt`：训练模型、配置和更新数。
- `training_history.csv`：每次更新的原始归一化损失、熵、熵系数和采样奖励均值。采样均值来自均衡状态批次，不是轨迹平均奖励或回合回报。
- `evaluation_history.csv`：包括初始随机策略在内的全部精确评估记录。
- `policy_values.npz`：各状态概率、贪心动作、Critic 值和精确策略价值。
- `state_diagnostics.csv`：方便逐格阅读的相同结果，行列编号从 1 开始。
- `ac_convergence.png`：无平滑的全状态评估；误差面板采用对称对数刻度，保留零值。
- `ac_training_metrics.png`：损失与熵的原始曲线和 100 次更新移动平均。
- `ac_policy_and_value.png`：策略与 Critic 图，目标格标为 Terminal，终止价值固定为 0。
- `seed_validation/`：四个附加随机种子的模型、完整历史和诊断。

原代码、旧 notebook 及旧图片已保存在 `output/ac_before_changes`，原来的 `output/ac_*.png` 也未用新实验覆盖。

`test_ac.py` 用独立标量规则检查全部 125 个状态动作组合，检查终止与 reset 契约、预先计算的最优价值和并列最优、带循环策略的精确价值，以及终止 TD 目标与状态间梯度隔离。
